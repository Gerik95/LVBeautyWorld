# Скины

Три независимых параметра:

- `locale`: `de` | `uk`
- `theme`: `system` | `light` | `dark`, на странице вычисляется `light` или `dark`
- `skin`: идентификатор оформления: `default` и сезонный `winter` (включает только сам посетитель)

Скин не меняет геометрию логотипа, сетку, маршруты, тексты, запись, доступность и юридические страницы. Он может подменить декоративные CSS-переменные, дать свои ресурсы и профиль эффектов.

## Где что лежит

| Файл | Роль |
| --- | --- |
| `src/skins/types.ts` | `SkinDefinition`, флаги эффектов |
| `src/skins/config.ts` | `activeSkinId`, общий `effectsEnabled` |
| `src/skins/registry.ts` | реестр и безопасный `getSkin` |
| `src/skins/default.ts` | единственный активный скин |
| `src/skins/motion.ts` | длительности |
| `src/components/hero/HeroDecorSlot.tsx` | слот декора Hero |
| `src/components/NavAccentSlot.tsx` | слот акцента навигации |
| `src/components/SiteDecorSlot.tsx` | слот общего слоя сайта (`loadSiteDecor`) |
| `src/components/skinDecor.tsx` | `useSkinDecor`: ленивый декор скина с `<html data-skin>` |
| `src/skins/runtime.ts` | скины по выбору посетителя, `lvbw-skin`, событие снежного шара |
| `src/skins/useSkinId.ts` | хук: текущий `data-skin`, следит за переключением |
| `src/components/SkinEgg.tsx` | пасхалка: три касания знака или встряхивание телефона |
| `src/skins/winter/` | зимний скин: токены, декор, `winter.css` |

Неизвестный или пустой id возвращает `default`. Слоты пустые, пока у скина нет `loadHeroDecor` / `loadNavAccent` / `loadSiteDecor`, поэтому неактивные декорации не загружаются. Слоты читают `data-skin` на `<html>`, а не `activeSkinId`, и подхватывают переключение без перезагрузки.

`effectsEnabled: false` выключает лампу, прожектор, блик кнопки, reveal и пробный ч/б фото разом. Скин не может включить прожектор в светлой теме и не обходит `prefers-reduced-motion`.

Галерея услуг на главной берёт оформление из токенов скина, а не из id скина. Ключи задаются отдельно для `light` и `dark` в `tokens`:

- `--svc-marker`, `--svc-marker-glow` — маркер активного направления
- `--svc-frame`, `--svc-photo-shadow` — рамка и тень кадра
- `--svc-gleam` — блик кромки; в светлой теме остаётся `transparent`
- `--svc-panel-ms`, `--svc-photo-ms`, `--svc-wave-in-ms`, `--svc-wave-out-ms`, `--svc-gleam-ms`, `--svc-reveal-ms`, `--svc-reveal-gap`, `--svc-reveal-shift` — длительности, их числа лежат в `galleryMotion`

Сезонный скин может подменить эти переменные, не переписывая выбор услуги. Волна, блик и появление всё равно выключены при `prefers-reduced-motion`.

Расписания по дате нет. Базовый скин задаётся в `config.ts`. Скины из `optInSkins` (`src/skins/runtime.ts`) посетитель включает сам, выбор хранится в `localStorage` под ключом `lvbw-skin` и действует только на его устройстве. `ThemeScript` ставит `data-skin` до отрисовки, `ThemeRuntime` повторяет это на странице 404: там Next отдаёт error shell без загрузочного скрипта. Часы салона считаются отдельно, в `src/content/schedule.ts`.

## Зимний скин `winter`

Включается только по выбору посетителя:

- три быстрых касания или клика по знаку (Hero и 404);
- встряхивание телефона там, где браузер даёт датчик движения без запроса разрешения (Android; на iOS запроса нет, работает тап);
- «Winterzauber / Зимова магія» в настройках, там же выключение.

После первого включения появляется короткая подсказка, где режим выключить. Повторный жест при включённой зиме только встряхивает снежный шар.

| Где | Что |
| --- | --- |
| Падающий снег | `snowfall.ts`: три слоя глубины (мелкие резкие, мягкие, крупные размытые «боке»), порывы ветра, у каждой снежинки своё покачивание. В тёмном Hero ярко видна только в луче прожектора |
| Главная целиком | `PageSnow`: снег за контентом по всей странице, движется вместе с прокруткой и ложится на сугроб в футере (`body` под скином прозрачный, холст `z-index: -1`) |
| Лежащий снег | `snowPaint.ts` (тело кэшируется в `SnowLayer`, искры дорисовываются поверх; размер комьев фиксирован, поэтому сугроб растёт вверх, а не «плывёт»): объём из градиента, комья со светом и тенью, зерно льда, мерцающие искры. Через него рисуются шапки, сугроб на 404 и сугроб в футере |
| Знак | шапки на верхних гранях L и V, найдены по пикселям SVG; надпись BEAUTY WORLD исключена по `logo-words.svg`. Курсор сметает снег по направлению движения комьями и пылью, край оседает, потом снег нарастает |
| Снежный шар | знак покачивается, снег взлетает метелью, шапки осыпаются |
| 404 | шапки на цифрах и сугроб у основания, тает под курсором |
| Ч/б фото и галерея | фото под зимой цветные, вместо ч/б — замёрзшее стекло (сила 70%, на телефоне без backdrop-blur): текстура `frostTexture.ts` (корка у краёв, ледяные папоротники, блики) поверх размытого фото; при наведении (на телефоне — фото в центре экрана) оттаивает из середины. В галерее оттаивает цветная волна |
| Часы на «Kontakt» | `HoursFrost`: пока салон закрыт — стекло замёрзшее, часы читаются; после открытия за 40 мин оттаивает с тёплым светом внутри, за 45 мин до закрытия снова покрывается инеем (`frostLevel.ts`). Предпросмотр: `?frost=0.5`, `?frost=cycle` |
| Капсула | иней по кромкам, под линзой оттаявшее окно |
| Кнопка записи | один блик по наведению и искра; в тёмном Hero искра горит от `--beam-hit` |
| Футер | реалистичный сугроб на кромке, растёт по мере прокрутки |
| Фавиконка | снежная шапка, при выключении возвращается исходная |
| Сильвестр | `fireworks.ts`: ракеты со шлейфом, пион, хризантема, ива, кольцо, кроссет, пальма, треск. 31.12 с 23:59 шоу, 00:00–00:02 финал, до 00:30. Залпы обходят текст Hero, частицы над текстом приглушены. Предпросмотр: `?silvester`, `?silvester=finale` |

Встряхивание телефона: датчик движения браузеры отдают только по HTTPS (или localhost). На iOS разрешение запрашивается третьим касанием по знаку или кнопкой «An» в настройках.

`prefers-reduced-motion`: снег стоит, шапки и сугроб сразу полные, без сбивания, шара и фейерверков. Canvas Hero засыпает, когда Hero не на экране или вкладка скрыта.

## Как добавить скин

1. Папка `src/skins/<id>/` с определением, токенами и ленивыми компонентами декора.
2. Зарегистрировать объект в `skinRegistry`.
3. Поставить `activeSkinId` в `config.ts` — или добавить id в `optInSkins`, чтобы скин включал сам посетитель.
4. Не копировать Hero и не разбрасывать условия по имени праздника.

Декор рендерится в уже существующих слотах, с `pointer-events: none`, и не перекрывает текст. Ресурсы подключаются через `loadHeroDecor` / `loadNavAccent` (`() => import(...)`), чтобы они не попадали в бандл выключенного скина.

## Проверки

- `default` выглядит как сейчас, без лишних запросов декора.
- Несуществующий id на `data-skin` возвращается к `default` (`ThemeRuntime`).
- Светлая тема не показывает луч и не запускает лампу. В тёмной теме без движения остаётся чёрный знак с контуром.
- `effectsEnabled: false` и `prefers-reduced-motion` оставляют стабильную страницу без розжига.
- Оба языка и обе темы сохраняют композицию, запись и юридические ссылки.
