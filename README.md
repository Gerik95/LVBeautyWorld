# LV Beauty World

Greenfield visiting-card website for **LV Beauty World**, a super-premium beauty salon in Dortmund, Germany.

The React site itself is **forthcoming**. This repository currently holds brand originals and web-ready logo exports so favicon, PWA/home-screen icons, and search/social images can use the real mark from the first implementation.

- Brand originals: `brand/originals/`
- Web-ready logos and icons: `public/brand/`

Code will live on Origin and on GitHub at [Gerik95/LVBeautyWorld](https://github.com/Gerik95/LVBeautyWorld).
